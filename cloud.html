Cloud Computing, What that is?

Cloud computing is a data storage service that is comercially available to the public. Cloud Computing is important in general because it can hold precious valuable juicy data. Data that we most probably don't want to lose. Many many very many people use cloud storage to back up their data, because losing data hurts 🤕
